**Repair (commit `b489dd1`):**
1. `pyproject.toml`: `[tool.pytest.ini_options] pythonpath = ["src", "."]`, so imports no longer depend on `.pth` files.
2. `.harness/ruff.toml`: `[lint.isort] known-first-party = ["splitkaro", "tests"]`, so classification is deterministic. No rule was disabled.
3. The 3 test files gained one blank line each (`git diff` = 3 insertions, 0 deletions, no assertion touched). Because the tests are locked, they were re-locked through `.harness/lock.py` with the reason recorded in `.harness/integrity.lock`.

**Not changed:** spec, assertions, thresholds (`gates.json`), application code in `src/`.
